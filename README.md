# melite-kimodo-nodes

Kimodo motion lane nodes.

Tech Noir Kimodo custom nodes for ComfyUI.

## Nodes

- `KimodoLoader`
- `KimodoTextToPose`

## Install

```bash
cd /path/to/ComfyUI/custom_nodes
git clone https://github.com/JayDataEngineer/melite-kimodo-nodes.git
```

Restart ComfyUI.
